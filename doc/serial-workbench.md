# 基础串口工作台（前端模拟版）

入口：应用顶部“串口工作台”。“组件演示”保留此前的组件对比页面。

## 已实现

- 模拟端口 DEMO-01 / DEMO-02，波特率、数据位、校验位和停止位选择；连接后锁定参数。
- 连接与断开，每秒生成模拟 RX 数据；发送后立即模拟 RX 回显。
- Dockview 日志、发送、命令面板，支持拖动和分屏；恢复布局不清除工作台数据。
- 接收文本/HEX 切换、大小写不敏感搜索、自动滚动、暂停显示、清空。
- 文本 UTF-8 编码，支持无行尾 / LF / CRLF；HEX 必须为完整字节，不追加行尾。
- 发送字节预览、Ctrl+Enter 发送、错误提示、快捷命令及最近 10 条发送历史。
- RX/TX 字节累计与手动归零。清空日志不清零计数。

## 边界

不枚举、不连接真实设备，不调用串口 Rust 后端。连接参数仅作界面模拟；没有连接失败或热拔插仿真。暂停仅冻结显示快照，接收及计数继续。日志最多缓存 500 条，淘汰数量可见；不提供录制或持久化。单次发送上限 4096 字节。

关闭 Dockview 面板可用“恢复面板布局”恢复；切换组件演示保留工作台状态，模拟连接仍会接收数据。刷新页面清除数据。

## 文件

- `src/serial/SerialWorkbench.tsx`：模拟状态、连接栏、Dockview 面板、收发交互。
- `src/serial/model.ts`：编码、格式化及数据模型。
- `src/serial/SerialWorkbench.css`：业务页面样式。
- `src/App.tsx`：工作台与组件演示导航。
- `src/ComponentGallery.tsx`：原组件演示入口。

## 验证

已执行前端生产构建及编码断言（UTF-8、多字节中文、HEX、非法输入、行尾和长度上限），在浏览器验证模拟连接、接收、发送回显和暂停显示。未进行真实串口或硬件性能验证。

桌面测试：`pnpm tauri dev`。仅构建前端：`pnpm build`。当前阶段不制作安装包。


## 多会话与旧版布局参考

- 默认提供三个独立演示会话，用 Dockview 标签拖拽换序，也可以拖到边缘分屏；新建会话最多 16 个。
- 各会话独立保存配置、连接状态、收发日志、计数、草稿与历史；切换标签不会停止模拟接收。关闭会话会销毁其状态并停止定时器，刷新页面清除全部模拟数据。
- 布局为顶部串口参数、左侧快捷命令、右侧接收日志与下方发送编辑器；保留 Ant Design 风格。
- 波特率可选择常用值，也可直接输入 1–4294967295 的整数；无效值不可连接。
- 数据位提供 5/6/7/8，停止位提供 1/2；校验提供无/奇/偶，流控制提供无/RTS/CTS/XON/XOFF。
- 与旧项目一致，MARK、SPACE、DTR/DSR 及混合流控制暂未支持，以下拉禁用项展示。所有选项仍只用于模拟配置，不访问串口硬件。


## 浏览器式会话标签（更新）

外层会话栏现由 `src/serial/SessionTabs.tsx` 管理，不再使用 Dockview 会话面板；内部日志、命令和发送区仍使用 Dockview。

- 标签末尾的 ＋ 新建会话；拖动到另一个标签前方插入换序。也可使用 Alt + 左右方向键换序。
- 双击标签或按 F2 编辑名称，Enter 保存、Escape 取消。未手动命名的标签会随选中的串口更新（选择与默认值相同的串口也会更新）；手动名称保留。
- 拖出应用内容区域松开可移至独立窗口，标签上不提供独立窗口按钮。浏览器弹窗受到浏览器策略约束；Tauri 使用 WebviewWindow。
- 将标签拖到另一个同源工作台窗口的标签栏即可合并。仅支持本应用窗口之间移动，不支持任意浏览器/其他应用窗口。
- 转移通过短期 localStorage 令牌和接收确认完成，包含配置、连接状态、日志、计数、暂停缓存、发送草稿及历史；原会话在移动时暂停模拟生成，目标确认后才删除原会话。15 秒未确认则保留原会话。内部面板布局和日志筛选属于视图状态，跨窗口恢复默认。
- 最后一个标签关闭或成功转移后自动关闭原窗口；手动打开的普通浏览器窗口可能被浏览器策略禁止脚本关闭，界面会提示手动关闭。
- Windows Tauri 必须使用 `dragDropEnabled: false`，让 HTML5 拖放事件进入前端。修改此项需要重新启动 `pnpm tauri dev`，前端热更新不能更新现有原生窗口的配置。
- 独立窗口权限仅匹配 `main` 和 `serial-*`，增加创建 WebviewWindow 和关闭当前窗口的权限。

验证：前端生产构建与 Rust 离线 cargo check；浏览器验证鼠标拖动换序、双击编辑、键盘换序、重复选择默认串口更新名称，以及独立窗口接收确认（移除按钮前验证）。原生 Windows 窗口间鼠标拖放仍需桌面端实测。


### 拖动预览与图标

关闭和新增使用统一细线 SVG，关闭按钮 22px 热区、12px 图标，新增按钮 26px 热区、14px 图标。
拖动使用包含会话界面的 HTML5 drag image；离开标签栏 18px 后隐藏原标签并显示其他会话，返回标签栏可继续排序。离开标签栏松手会请求创建独立窗口，失败时恢复原会话。
注意：跟随鼠标的是静态页面预览，不是 Edge 的实时原生窗口；新窗口仍在松手后创建。实时原生窗口跟随与跨窗口吸附需要另行实现窗口拖动协调，当前未完成。


### Windows 原生窗口拖动（最新实现）

Windows Tauri 不再使用 HTML5 半透明拖拽图像，改用 `nativeSessionDrag.ts` 驱动实际窗口。Rust 命令 `session_drag_pointer` 仅在用户按住标签时读取鼠标位置、主键和 Esc 状态；不存在后台键盘记录。

- 一个标签：直接移动当前窗口，不生成空窗口或新窗口副本。
- 多个标签：越过标签栏阈值后创建真实窗口，目标完成接收后移除原标签；窗口保持不透明。
- 位置始终使用物理屏幕坐标和固定抓取偏移，松手和移动帧走同一定位逻辑，支持负屏幕坐标。
- 移入另一个工作台的标签栏显示插入提示，释放后通过接收确认转移；拒绝隐藏、正在转移或已满的窗口。最后一个标签移走后关闭来源窗口。
- Esc：单窗口回到原位置；拆分窗口请求合并回来源窗口。接收失败则保留拥有会话的窗口。
- 普通网页保留浏览器拖放回退路径，仍受系统半透明拖拽影像、弹窗策略和位置控制限制；页面标记“网页预览”。本节替代前文关于桌面端“仅松手后创建”的限制描述。

验证：TypeScript/Vite 构建、Rust 离线检查、5 项坐标与合并目标测试通过。尚未通过原生桌面 UI 自动化验证真实拖动、跨 DPI 切换与跨窗口合并；不要将逻辑单测视为桌面端交互验收。必须重新运行 `pnpm tauri dev` 加载新增 Rust 命令及窗口权限。


### 精简工作台与标签重叠判定

应用直接进入串口工作台，不再提供组件演示导航和顶部介绍行。内容区第一行为会话标签，页面和新建原生窗口统一使用“串口调试工具”标题。
原生合并按拖动标签与目标标签的实际矩形重叠面积判断，选择重叠最大的标签，并按左右位置决定插入顺序。标签栏空白、仅贴边或垂直错开不合并。坐标与重叠规则共 8 项单测通过，原生跨窗口交互仍需桌面端验收。


拆分回归修复：原生拖动起点使用 pointerdown 的坐标，避免 IPC 返回过晚导致丢失起点；越过阈值且已离开标签区域，即使采样时鼠标已松开也完成拆分。横向空白区域与纵向脱离使用相同的标签矩形重叠规则。坐标与回归测试共 11 项。


最新合并规则：判断拖动标签与目标窗口的整条标签栏是否有正面积重叠（包括右侧空白），不要求覆盖某一个标签。按拖动标签的横向中心决定插入位置，落在右侧空白则追加到末尾。仅接触边缘或完全离开标签栏时不合并。此规则替代前文的单标签重叠规则；网页回退也允许向标签栏空白处放入。
